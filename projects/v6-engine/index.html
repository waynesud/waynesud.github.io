V6 Engine

Project Overview

This project is a complete V6 engine assembly that I modeled in SolidWorks. The final assembly consists of 30 unique parts, all created from engineering drawings.

This was a fun project that helped me brush up on my CAD fundamentals while also pushing me to learn new techniques. One of the biggest takeaways was getting comfortable modeling curved geometry using splines and lofts, which was something I hadn’t done much before.

The original design and reference drawings were created by Alex Engineering, who also generously provides a full video walkthrough. I intentionally avoided following the video step-by-step and relied primarily on the drawings instead, using the video only when I got stuck (mainly while modeling the turbo and intake and exhaust manifolds). This made the project more challenging but also a lot more rewarding.
